# Pando

A git platform for monorepos, built on Cloudflare Artifacts for the "Build the next-gen git platform" competition (submit by October 14, 2026, 11:59 PM Pacific).

The proposal and the owner`s decisions live in the Plannotator Workspaces meta layer: `research/plans/pando-2026-10-02/PROPOSAL.md`. This repository is the public, open-source build; it carries no secrets and no private code copied without the owner`s word.

Layout: `worktrees/main` is the integration checkout; every branch gets a sibling worktree.
