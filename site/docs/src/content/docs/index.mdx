---
title: Pando
description: A git platform for monorepos, built on Cloudflare Workers and Artifacts, for many agents working at once.
---

Pando hosts monorepos. A monorepo is a folder of git repos under `projects/`, plus the files around them: notes, decisions, plans. Each repo has its own history, branches and checks. Each branch gets its own folder, a worktree, so many agents can work on one monorepo at once without getting in each other's way.

You work with plain git and the `pando` command. The web app shows your monorepos, their files, branches, checks and activity.
