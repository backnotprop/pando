---
title: Pando
description: A git platform for monorepos, built on Cloudflare Workers and Artifacts, for many agents working at once.
---

Pando hosts repositories. A repository on Pando is a folder of projects, each its own git repo, under `projects/`, plus the files around them: notes, decisions, plans. Each project has its own history, branches and checks. Each branch gets its own folder, a worktree, so many agents can work on one repository at once without getting in each other's way.

You work with plain git and the `pando` command. The web app shows your repositories, their files, branches, checks and activity.
